# Python для баз даних — Prometheus

Мої завдання з [курсу Prometheus](https://apps.prometheus.org.ua/learning/course/course-v1:Prometheus+PFDAT101+2024_T3/home): робота з SQLite, імпорт TXT/CSV/JSON та SQL-запити.

## Проєкти

| Папка / програма | Що я роблю | Результат |
| --- | --- | --- |

## Запуск

Потрібен Python 3 без додаткових бібліотек. Із папки проєкту запускаю відповідний `.py`, наприклад:

```bash
cd roster
python3 roster.py
```

На запит імені файлу натискаю **Enter**. Програма заново створює таблиці своєї бази. У `age_table` лише готова база, яку відкриваю в DB Browser for SQLite.

## Перевірка

Усі 7 програм перевірено повторним запуском, усі 10 баз — на цілісність. Виправлено пропуск першого рядка CSV у бібліотеці та музичних проєктах.

Обмеження музичної схеми з умови: однойменні треки й альбоми об’єднуються, тому альбоми різних виконавців з однаковою назвою можуть мати спільного виконавця.
